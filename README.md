# LAST SEEN 1.0

Русскоязычная детективная игра в интерфейсе найденного телефона. Первый эпизод посвящён событиям у торгового центра 13 ноября.

Открывайте приложения, сохраняйте материалы в журнал и примите финальное решение. В эпизоде четыре улики и три концовки. Браузер хранит ответы, заметки, журнал и список открытых концовок. При повторном прохождении заметки и список концовок сохраняются.

## Локальный запуск

Нужен любой статический HTTP-сервер. Например, из корня проекта:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000/. Для тестов с Node.js 22 или новее запустите:

```sh
node --test
```

## GitHub Pages

В настройках репозитория, в разделе **Pages → Build and deployment**, выберите **GitHub Actions**. Workflow проверяет каждый pull request и публикует статические файлы после успешных тестов на основной ветке. При необходимости его можно запустить вручную с основной ветки.
