# LAST SEEN 1.1 — Complete Experience

Эпизод 01 «21:41» — русскоязычный детективный триллер в интерфейсе смартфона. Персонажи, фотографии, новости и звонки вымышлены. Игра не отправляет сообщения, не звонит на реальные номера и не требует аккаунта.

[Играть на GitHub Pages](https://aurones.github.io/LAST-SEEN/)

На iPhone откройте игру в Safari. Для запуска в отдельном окне нажмите «Поделиться» → «На экран Домой». Установка необязательна. После первой полной загрузки сервисный работник сохраняет ресурсы для офлайн-игры. Прогресс и настройки хранятся в этом браузере. Сохранение 1.0 определяется при запуске, но из-за нового сценария требуется начать заново.

## Разработка

Запустите статический сервер из корня проекта, например `python3 -m http.server 3000`. Откройте http://localhost:3000/.

- `node --test` запускает проверки условий сюжета, сохранений и статических ресурсов.
- Для браузерной проверки установите Python Playwright и выбранный браузер. Запустите `python test/browser.py --engine chromium --screenshots /tmp/last-seen-shots` или выберите `--engine webkit`.
- Браузерные тесты поднимают свой локальный сервер и проверяют прохождение без сервера приложения.

## Публикация

Workflow запускает тесты на push и PR. Он собирает игровой сайт из списка ресурсов. GitHub Pages публикует основную ветку. В веточном режиме каталог `docs` исключён правилами Jekyll, поэтому файл канона не входит в сайт. Версию ключа кеша, URL ресурсов в HTML и список в `sw.js` обновляйте вместе при следующем изменении ресурсов.
